# 재잘

하루 5분, 입으로 굳히는 영어 덩어리 표현 학습 앱.

- 간격 반복(FSRS 방식), 떠올리기 연습, 듣고 고르기, 단어 조립, 섀도잉
- AI 상황극: WebLLM + WebGPU로 Qwen2.5 모델을 **기기 안에서** 실행 (Web Worker에서 추론해 화면이 멈추지 않음)
  - 틀린 문장은 먼저 힌트를 주고 스스로 고칠 기회를 준 뒤 정답을 보여 줌 (elicitation → recast)
  - 오류 유형(관사·전치사·시제 등) 누적, 대화 후 복잡성·정확성·유창성(WPM) 피드백, 고친 문장을 복습 카드로
- 음성 출력은 기기 음성, 학습 기록은 기기에 저장
- 음성 입력은 브라우저의 음성인식 서비스를 사용 (Chrome 등은 음성을 브라우저 공급자 서버에서 인식함). AI 대화 처리는 기기 안에서 이뤄짐

AI 대화는 WebGPU를 지원하는 브라우저(최신 Android Chrome, iOS 26+ Safari, 데스크톱 Chrome/Edge)에서 동작합니다. 모델은 처음 한 번 내려받은 뒤 브라우저에 저장됩니다.

## 화면

- 마스코트 **앵두**(앵무새 병아리)가 정답·오답에 반응하고, 원어민 음성에 맞춰 부리를 움직임
- 첫 실행 온보딩(하루 목표·관심 상황·소리/마이크 확인), 7일 출석 도장, 상황별 진행
- 엄지 영역 버튼, 큰 마이크와 말 끝나면 자동 채점, 하단 피드백 시트, 세션 축하 화면
- 설정: 하루 목표, 효과음, 진동, 핸즈프리 대화, 번역 먼저 보기, 말하기 속도, 학습 기록 내보내기·가져오기

## 실력 진단과 코스

- 메뉴: **홈 · 코스 · AI 대화 · 표현함 · 나** (연구 근거 화면은 '나' 안으로)
- 실력 진단(3~4분): CEFR 자기 평가 1문항 → 적응형 10문항(듣고 뜻 고르기 / 한국어→영어 말하기) → 30초 자기소개(분당 단어 수로 보정) → 추천 레벨 A1~B2, 직접 조정 가능
- 진단에서 맞힌 표현은 새로 가르치지 않고 복습으로 넘김
- 코스: 레벨(A1~B2) × 상황 단원. 관심 상황이 먼저, 지금 단원부터 새 표현을 꺼내고, 단원마다 AI 상황극 미션
- 표현 481개 (상황 12개 × 레벨 4개, 칸마다 10개 이상), AI 상황극 15개

## 단어 공부

- 말하다 놓친 표현에서 **빠진 내용어**를 뽑아, 자주 쓰는 단어(빈도 상위 ~3,000)는 자동으로, 드문 단어는 골라서 단어장에 담음
- 단어 카드: 뜻·품사·빈도 구간, 긴 단어는 **단어 해부**(예: re + serv + ation), 관용 표현은 생긴 이야기, 그 단어를 만난 원래 표현
- 복습: 뜻 고르기 → 원래 표현의 빈칸 채우기, 간격 반복으로 일정 관리
- 단어 사전 551개(content.js), 그중 213개에 단어 해부·기억 이야기, 빈도 구간은 NGSL·COCA를 참고한 근사치
- 모든 단어에 미국식 발음기호(CMU 발음사전 기반, 품사에 따라 read /rid/·close /kloʊz/처럼 맞춤). AI가 정리한 사전 밖 단어도 발음기호 포함

## 매일 오고 싶게 (게이미피케이션)

- **체리**: 학습 행동(미션·상자·연속 기록·배지·단원 완료)으로만 모으는 앱 화폐. 최근 기록을 상점에서 확인
- **오늘의 미션 3개**: 날짜로 정해지는 미션(복습, 말로 답하기, 콤보 등). 미션마다 체리 +5, 다 하면 보상 상자(체리 10~20개, 범위 공개)
- **연속 기록 보호권**: 하루 빠져도 앱을 열 때 자동으로 써서 기록 유지(최대 2개). 3·7·14·30·50·66·100·200·365일 마일스톤 보상
- **앵두 꾸미기**: 모자·안경·장식·목 액세서리 12종을 입혀 보고 구매. 왕관(100일 연속)·졸업모(레벨 졸업)는 배지로만 열림. 2배 XP 15분 아이템
- **배지 19종**: 잠긴 배지도 진행도 표시. 66일 습관 배지 포함
- **지난주의 나와 대결**: 가짜 경쟁자 없이 이번 주와 지난주 같은 요일까지의 XP 비교
- **앱 안 알림만**: 앵두 말풍선이 상황별로 바뀜(밤 8시 이후 기록 위험, 보호권 사용, 약속한 공부 시간, 상자·마일스톤 임박). 3일 이상 쉬면 복귀 환영과 가벼운 3분 세션. 탭에 복습 수·새 소식 표시
- 앱을 닫으면 알림이 오지 않음(푸시 없음). 모든 기록은 각자의 기기 브라우저에 따로 저장
