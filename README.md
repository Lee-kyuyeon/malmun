# 재잘

하루 5분, 입으로 굳히는 영어 덩어리 표현 학습 앱.

- 간격 반복(FSRS 방식), 떠올리기 연습, 듣고 고르기, 단어 조립, 섀도잉
- AI 상황극: WebLLM + WebGPU로 Qwen2.5 모델을 **기기 안에서** 실행 (Web Worker에서 추론해 화면이 멈추지 않음)
  - 틀린 문장은 먼저 힌트를 주고 스스로 고칠 기회를 준 뒤 정답을 보여 줌 (elicitation → recast)
  - 오류 유형(관사·전치사·시제 등) 누적, 대화 후 복잡성·정확성·유창성(WPM) 피드백, 고친 문장을 복습 카드로
- 음성 출력: 표현·단어·에피소드는 오픈 신경망 음성(Kokoro-82M)으로 미리 녹음한 원어민 음성, AI 대화는 기기 음성. 학습 기록은 기기에 저장
- 음성 입력은 브라우저의 음성인식 서비스를 사용 (Chrome 등은 음성을 브라우저 공급자 서버에서 인식함). AI 대화 처리는 기기 안에서 이뤄짐

AI 대화는 WebGPU를 지원하는 브라우저(최신 Android Chrome, iOS 26+ Safari, 데스크톱 Chrome/Edge)에서 동작합니다. 모델은 처음 한 번 내려받은 뒤 브라우저에 저장됩니다.

## 화면

- 마스코트 **앵두**(앵무새 병아리)가 정답·오답에 반응하고, 원어민 음성에 맞춰 부리를 움직임
- 첫 실행 온보딩(하루 목표·관심 상황·소리/마이크 확인), 7일 출석 도장, 상황별 진행
- 엄지 영역 버튼, 큰 마이크와 말 끝나면 자동 채점, 하단 피드백 시트, 세션 축하 화면
- 설정: 하루 목표, 효과음, 진동, 핸즈프리 대화, 번역 먼저 보기, 말하기 속도, 학습 기록 내보내기·가져오기

## 실력 진단과 코스

- 메뉴: **홈 · 코스 · AI 대화 · 표현함 · 나** (연구 근거 화면은 '나' 안으로)
- 실력 진단(3~4분): CEFR 자기 평가 1문항 → 적응형 10문항(듣고 뜻 고르기 / 한국어→영어 말하기) → 30초 자기소개(분당 단어 수로 보정) → 추천 레벨 A1~C1, 직접 조정 가능
- 진단에서 맞힌 표현은 새로 가르치지 않고 복습으로 넘김
- 코스: 레벨(A1~B2) × 상황 단원. 관심 상황이 먼저, 지금 단원부터 새 표현을 꺼내고, 단원마다 AI 상황극 미션
- 표현 1,501개 (상황 12개 × 레벨 5개 A1~C1, 칸마다 25개, 하루 6개씩 약 250일 분량), AI 상황극 36개
- 단원 안에서는 쉬운 표현부터, 진단은 '60% 이상 맞힌 가장 높은 레벨'로 판정 (검수·재검토 기록: docs/content-review.md)

## 원어민 음성

- 표현 1,201개(+대체 표현), 단어 1,036개, 해외살이 대사를 **Kokoro-82M**(Apache-2.0 오픈 모델)으로 미리 녹음해 `audio/`에 담음. 무료, 서버 없음
- 미국 화자 6명이 표현마다 돌아가며 말하고, 표현마다 두 번째 목소리(B1 이상은 영국 억양)가 있어 '다른 목소리'로 들어 볼 수 있음
- 클립 약 3,760개, 약 31MB(AAC). 단어는 한 단어 문장처럼 조금 천천히 읽어 짧은 단어도 또렷하게. 들은 클립은 자동 저장되고, 설정에서 전부 받아 두면 비행기 모드에서도 재생
- 녹음 파일이 없는 문장(AI 대답, 내가 담은 문장)은 기기 음성으로 읽음. 기기 음성도 Premium·Enhanced·Neural 음성을 먼저 고름
- 다시 녹음하기: `tools/tts/gen.py` 맨 위 설명대로. 빠진 클립만 새로 만들고 `audio/manifest.js`를 갱신함

## 앵두와 해외살이 (귀 트이기)

- 시애틀에 막 이사 온 설정의 에피소드 6편(공항·카페·이웃·약국·대중교통·직장 첫날), 장면 26개
- 장면마다 **자막 없이 먼저 듣고 들은 대로 행동**하기. 잘못 고르면 이야기 속에서 일이 꼬이고(엉뚱한 음료, 놓친 바비큐) 다시 들어 볼 수 있음
- 난이도는 한국 대학생 기준(읽기·문법은 되지만 실제 속도 듣기가 약한 수준). 에피소드 A2→B2, 실제보다 조금 빠르게 녹음(1.05~1.15배), 필러·축약·말 바꾸기가 들어간 대사
- 상황 설명과 질문만으로는 답을 찍을 수 없고, 오답 선택지는 모두 대사에 실제로 나온 정보(함정 숫자, 바뀐 약속, 부정문)
- 도움은 한 칸씩: 천천히 듣기 → 핵심 단어 → 영어 자막 → 한국어 번역. 실제 대화처럼 '다시 말해 주세요'는 한 번까지 무료
- '자막 없이 알아들음' = 첫 선택이 맞고, 도움을 쓰지 않고, 두 번 안에 들었을 때
- 해결하면 자막·번역·귀 팁(연음, forty/fourteen 같은 소리 구분)과 단어 담기
- **귀 트임 지표**: 최근 30장면 중 자막 없이 알아들은 비율. 홈과 해외살이 화면에 표시
- 첫 화와 내 레벨 이하 에피소드는 바로 열리고, 나머지는 앞 이야기를 들으면 열림. 미션 '해외살이 장면 3개 듣기', 배지 '귀가 트였다'

## 30초 말하기

- 단원 표현을 6개 이상 익히면 열려요. 하루 한 번 '오늘의 5분' 끝에 나오고, 코스 화면에서 언제든 할 수 있어요
- 질문 180개(상황 12 × 레벨 5 × 3개)와 이 단원에서 익힌 표현 2~3개가 주어지고, 30초 동안 이어서 말해요(연속 음성 인식)
- 기기 안에서 바로 채점: 단어 수(레벨별 목표 A1 8 ~ C1 60), 단원 표현 사용(답변 속 구간과 LCS 일치), 분당 단어 수, 문장당 단어 수. 기기 안 AI가 준비돼 있으면 다듬은 답변, 잘한 점, 고칠 점도 보여 줘요
- 쓴 표현은 간격 반복에 '좋음'으로 반영되고, '나' 탭 '말하기 성장'에서 최근 답변 길이·속도 추이를 봐요

## 단어 공부

- 말하다 놓친 표현에서 **빠진 내용어**를 뽑아, 자주 쓰는 단어(빈도 상위 ~3,000)는 자동으로, 드문 단어는 골라서 단어장에 담음
- 단어 카드: 뜻·품사·빈도 구간, 긴 단어는 **단어 해부**(예: re + serv + ation), 관용 표현은 생긴 이야기, 그 단어를 만난 원래 표현
- 어디서든 담기: 듣기·따라 말하기·피드백·AI 대화 속 영어 단어를 누르면 단어 카드가 열리고 바로 담을 수 있음
- 단어 학습 단계: 만나기(소리·발음기호·뜻·해부·문장) → 뜻 알아보기 → 원래 문장 빈칸 → 한→영 떠올리기 → 다른 문장 빈칸 → 내 문장 만들기(기기 안 AI가 확인). 맞히면 한 칸 위, 틀리면 한 칸 아래, 복습 간격은 간격 반복으로 관리
- 세션마다 단어 최대 3개(새 단어 2개), 표현함 '단어만 복습하기'로 단어 전용 세션, 새 단어는 하루 5개까지
- '나' 탭에 단어 단계별 개수
- 단어 사전 1,362개(content.js), 그중 496개에 단어 해부·기억 이야기, 빈도 구간은 NGSL·COCA를 참고한 근사치
- 모든 단어에 미국식 발음기호(CMU 발음사전 기반, tools/ipa.py로 생성, 품사에 따라 read /rid/·close /kloʊz/처럼 맞춤). AI가 정리한 사전 밖 단어도 발음기호 포함

## 매일 오고 싶게 (게이미피케이션)

- **체리**: 학습 행동(미션·상자·연속 기록·배지·단원 완료)으로만 모으는 앱 화폐. 최근 기록을 상점에서 확인
- **오늘의 미션 3개**: 날짜로 정해지는 미션(복습, 말로 답하기, 콤보 등). 미션마다 체리 +5, 다 하면 보상 상자(체리 10~20개, 범위 공개)
- **연속 기록 보호권**: 하루 빠져도 앱을 열 때 자동으로 써서 기록 유지(최대 2개). 3·7·14·30·50·66·100·200·365일 마일스톤 보상
- **앵두 꾸미기**: 모자·안경·장식·목 액세서리 12종을 입혀 보고 구매. 왕관(100일 연속)·졸업모(레벨 졸업)는 배지로만 열림. 2배 XP 15분 아이템
- **배지 20종**: 잠긴 배지도 진행도 표시. 66일 습관 배지 포함
- **지난주의 나와 대결**: 가짜 경쟁자 없이 이번 주와 지난주 같은 요일까지의 XP 비교
- **앱 안 알림만**: 앵두 말풍선이 상황별로 바뀜(밤 8시 이후 기록 위험, 보호권 사용, 약속한 공부 시간, 상자·마일스톤 임박). 3일 이상 쉬면 복귀 환영과 가벼운 3분 세션. 탭에 복습 수·새 소식 표시
- 앱을 닫으면 알림이 오지 않음(푸시 없음). 모든 기록은 각자의 기기 브라우저에 따로 저장

## 홈 화면에 추가 (PWA)

- Android Chrome: 홈 또는 '나' 탭의 **홈 화면에 추가** → 설치. 메뉴(⋮) → '홈 화면에 추가'/'앱 설치'로도 가능
- iPhone: Safari 공유 버튼 → '홈 화면에 추가'
- 설치하면 주소창 없이 앱처럼 열리고, 앱 파일을 캐시해 오프라인에서도 학습 가능(AI 모델은 한 번 받은 뒤 오프라인 동작)
- 길게 누르면 바로가기: 오늘의 5분 · 단어만 복습 · AI 상황극

## 앵두가 화나요

- 공부를 쉰 날수에 따라 앵두 표정이 바뀜: 2일 삐짐 → 3~4일 화남(찌푸린 눈썹·핏대) → 5일 이상 폭발(김 나고 부들부들)
- 홈 말풍선과 로고, 복귀 환영 화면에 반영되고, 5분 공부하면 "화 풀렸어!"로 풀림
- 홈 화면 아이콘 그림은 웹앱이 바꿀 수 없어 앱 안에서 보여 줌. 앱을 닫아 둔 동안 알림을 보내려면 서버(웹 푸시)가 필요

## 아이폰에서 쓰기

- Safari(또는 iOS 16.4+ Chrome) 공유 → 홈 화면에 추가. 시작 화면 이미지 포함
- 아이폰은 Safari와 홈 화면 앱의 기록이 **따로** 저장됨 → 설치 안내에서 기록을 내보내고, 홈 화면 앱 첫 화면의 'Safari에서 쓰던 기록 가져오기'로 이어 가기
- 백업은 공유 시트로 '파일에 저장'. 5번 이상 공부하면 2주마다 백업 알림 카드
- 설정 '아이콘에 복습 수 표시'(iOS 16.4+ 홈 화면 앱, 알림 권한 필요하지만 알림은 보내지 않음)
- 세션·AI 대화 중 화면 꺼짐 방지, 기록 카드 이미지 공유, 오프라인이면 말하기 대신 타이핑
- Android: 다른 앱에서 공유한 영어 문장을 재잘로 보내 내 표현·단어로 담기

## 코드 구조

빌드 도구 없이 GitHub Pages에 그대로 올리는 정적 앱입니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 메타·아이콘·스크립트 연결 |
| `app.css` | 스타일(라이트·다크) |
| `content.js` | 표현 1,501개, 상황극 36개, 단어 1,362개(발음기호 포함) |
| `content-abroad.js` | 해외살이 에피소드(장면·대사·선택지·결과·귀 팁) |
| `audio/` · `tools/tts/` | 녹음된 원어민 음성과 목록(`manifest.js`), 녹음 스크립트 |
| `js/core.js` | 공통 도구, 저장(한 번에 모아 쓰기)·마이그레이션, 앵두 SVG, 효과음, 시트, 화면 꺼짐 방지 |
| `js/device.js` | 음성 입출력, 기기 안 AI(WebLLM) |
| `js/words.js` | 채점, 단어장, 단어 단계, 간격 반복(FSRS) |
| `js/game.js` | XP·연속 기록, 체리·미션·배지·상점, 화난 앵두 |
| `js/app.js` | 라우터, 온보딩, 설정, 커리큘럼 |
| `js/learn.js` · `js/talk.js` · `js/screens.js` | 홈·세션 / AI 상황극 / 진단·코스·나·표현함·원리 |
| `js/abroad.js` | 해외살이 화면, 도움 단계, 귀 트임 지표 |
| `js/pwa.js` · `js/main.js` | 설치·백업·공유·배지·오프라인 / 시작 |
| `sw.js` · `manifest.webmanifest` · `icons/` | 오프라인 캐시, 앱 정보, 아이콘·시작 화면 |
| `tools/ipa.py` · `docs/` | 발음기호 생성기 / 콘텐츠 검수 기록 |

`js/` 파일은 순서대로 읽히는 일반 스크립트로 전역을 공유합니다. 뒤 파일의 함수는 함수 안에서만 부릅니다(로드 시점 호출 금지).

## 테스트

```bash
npm install && npx playwright install chromium
npm test
```

내용 점검(레벨 길이·유사 문장 포함), 브라우저 테스트(회귀·UX·진단·단어·대화·게임·단어 단계), 커리큘럼(단원 순서·레벨 사다리·진단 시뮬레이션), 설치·오프라인·아이폰 기능 테스트, 속도 측정까지 12종. GitHub에 push하면 Actions에서도 실행됩니다.
